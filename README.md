# 📊 TRAFFIC INSIGHT (트래픽 인사이트)

다채널 실시간 트래픽, 검색 트렌드 및 글로벌 외신 AI 원인 분석 대시보드 플랫폼입니다.

---

## ⚡ 빠른 시작 (다른 PC에서 실행 방법)

### 방법 1. 원클릭 실행 (가장 추천)
- 폴더 내 **`run_dashboard.bat`** 파일을 더블 클릭합니다.
- `node_modules`가 없으면 자동으로 `npm install`을 실행한 뒤 브라우저를 띄워줍니다.

### 방법 2. 터미널 명령어로 실행
```bash
# 1. 의존성 설치 (최초 1회 또는 패키지 폴더 없을 때)
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

---

## 📁 다른 PC로 프로젝트 이동(백업/전송) 시 팁
- `node_modules` 폴더와 `dist` 폴더는 파일 수가 많고 용량이 크므로 **제외하고 압축**하여 전송하는 것을 권장합니다.
- 다른 PC에서 폴더를 풀고 `run_dashboard.bat`을 실행하면 자동으로 필요한 패키지를 내려받고 실행됩니다.
- 구글 뉴스 크롤링(`/api/news`) 및 영문 외신 번역(`/api/translate`) 미들웨어가 **Vite 개발 서버 내부에 자체 내장**되어 있으므로, 별도의 백엔드 프로세스(`node server.js`)를 띄우지 않아도 모든 기능이 100% 정상 작동합니다.

## 🛠 주요 핵심 기능 및 구현 현황

1. **실시간 트렌드 & 외신 분석 (`/today`)**
   - **위키피디아 급상승 문서**: 한국어(ko) 및 영어(en) 실시간/과거 특정일자별 문서 순위 및 조회수 추이 조회.
   - **AI 뉴스 원인 분석**:
     - 구글 뉴스 RSS 실시간 크롤링 (최대 25건 표본 수집).
     - 엄격한 정규식 단어 경계(`\b`) 및 20건 다수결(Score-based Voting)을 통한 오분류 방지 (시상식/수상, 부고/추모, 신작/출시, 논란/사법, 경제/실적).
     - 트래픽 급증을 유발한 실제 대표 기사 직접 인용 (`📰 핵심 헤드라인 근거`).
   - **영문 외신 실시간 한국어 번역**:
     - 영문 외신 선택 시 브라우저 내에서 원클릭으로 한국어 번역 ON/OFF 토글.
     - 국문/영문 병기 헤드라인 지원.

2. **GA4 트래픽 대시보드 (`/dashboard`)**
   - DAU, 신규 사용자, 세션, 페이지뷰 KPI 카드 (기간별 유연 계산).
   - 일별 vs 주간 합계(7일 누적) 토글 인터랙티브 차트.
   - 관심 키워드 로컬 스토리지 북마크 관리.
   - **데이터 백업 & 복원**: 원클릭 JSON 백업 다운로드 및 업로드 지원 (중복 데이터 발생 시 더 많은 정보를 가진 파일 우선 자동 병합).
   - **관리자 권한 분리**: 기본 비밀번호 `admin` 기반 인증 시스템 내장 (일반 뷰어 모드에서는 데이터 오염 방지를 위해 복원/삭제 기능 보호).

3. **다채널 비교 탐색 (`/explore`)**
   - 위키피디아, npm 다운로드, crates.io 패키지 트래픽 지표 통합 조회.
   - 7일 / 30일 / 90일 / 1년 기간 필터.

4. **트렌드 맞대결 리포트 (`/report`)**
   - 두 키워드 간 실시간 트래픽 맞대결 및 승자 판정 배너.
   - 고해상도 맞대결 카드 PNG 이미지 내보내기 지원 (`html-to-image`).

## 🏗 프로젝트 디렉토리 구조
```
app-insight/
├── src/
│   ├── components/         # 대시보드, 뉴스 분석, 트렌드 차트 컴포넌트
│   │   ├── NewsAnalyzer.tsx       # AI 뉴스 원인 분석 & 번역 뷰어
│   │   ├── TrendingWiki.tsx       # 위키피디아 트렌드 & 과거 아카이브
│   │   └── dashboard/             # 대시보드 분할 컴포넌트들
│   ├── pages/              # 주요 라우트 페이지 (Home, Today, Dashboard, Explore, Report)
│   ├── services/           # API 통신 및 데이터 처리 레이어
│   │   ├── metricsService.ts      # 위키, npm, crates 트래픽 통합 서비스
│   │   ├── translateService.ts    # 4단계 폴백 영한 번역 서비스
│   │   ├── bookmarkService.ts     # 로컬 북마크 서비스
│   │   └── googleSuggest.ts       # 구글 연관 검색어 제안
│   ├── App.tsx             # 라우터 설정
│   └── main.tsx
├── vite.config.ts          # Vite 설정 + 자체 뉴스/번역 미들웨어 플러그인
├── server.js               # 선택적 Express 백엔드 (GA4 실제 API 연동용)
├── run_dashboard.bat       # Windows 원클릭 자동 실행 스크립트
└── package.json
```
